# My Ruby Project

A Ruby project created with Claude Code.

## Setup

```bash
bundle install
```

## Running the Claude Agent

Set your OpenAI API key as an environment variable:

```bash
export OPENAI_API_KEY=your-key-here
```

Then run:

```bash
./claude.rb
```

## Project Structure

- `lib/` - Source code
- `claude.rb` - OpenAI-powered coding assistant with file tools
